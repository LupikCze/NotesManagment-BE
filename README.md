# Project info
Web application for users to capture an inspiration when it strikes! The application should simply provide the quickest way to offload ideas, thoughts, and to-dos without losing focus. An application consists of two parts: backend in Java and frontend in React.

## App roles
1. User can create, view, edit and delete his own notes,note groups.
3. User can assign or remove note to/from note group.
4. User can assign a tag to note.
5. User can assign a tag to note group.
6. Admin can create, view, edit and delete Users + all the users permissions
